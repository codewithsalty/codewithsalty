# Custom README Icons

These icons are intentionally minimal: transparent background, crimson red `#DC143C`,
thin-line geometry, and consistent 32×32 sizing.

Use them from the README like:

```html
<img src="./assets/icons/about.svg" width="20" alt="">
```

Current set:
- about.svg
- systems.svg
- projects.svg
- experience.svg
- stack.svg
- activity.svg
- achievements.svg
- connect.svg
